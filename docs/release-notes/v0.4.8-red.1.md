## 在其他电脑安装

需要 DeepSeek Harness / DSH **0.2.1-rc.3 或更新版本**。

安装包地址：

```text
https://github.com/DescartHsu/dsh-pet/releases/download/v0.4.8-red.1/dsh-pet.tgz
```

在 Harness 的「插件 → 添加插件」中输入上面的完整安装包地址，完成安装后启用插件。
如果界面不接受安装包地址，可在已配置 `dsh` 命令的终端执行：

```powershell
dsh plugin --profile desktop add 'https://github.com/DescartHsu/dsh-pet/releases/download/v0.4.8-red.1/dsh-pet.tgz'
```

重启 Harness，然后在「设置 → 宠物」中选择 **鲸鱼娘（红色）**。
请下载附件 `dsh-pet.tgz`；GitHub 自动生成的 Source code ZIP/TAR 是源码，不是编译好的插件安装包。

已有宠物配置和存档无需手工删除。若之后通过 npm 的 `@latest` 升级，可能会切回原作者发行版。

`SHA256SUMS` 可用于校验安装包：

```powershell
Get-FileHash .\dsh-pet.tgz -Algorithm SHA256
```
